# Windoora Engineering — ERP & 1-Year Financial Ledger

A responsive web and mobile-ready ERP & 1-Year Financial Ledger tailored for **Windoora Engineering** (UPVC Doors, Windows & Architectural Contracting).

## Key Features
- **Website View & App View Toggle**: Seamlessly switch between a full desktop dashboard and an interactive mobile app viewport.
- **1-Year Annual Ledger (FY 2026–27)**: Month-by-month tracking of customer receipts, supplier purchases, daily operational expenses, and net cash flow.
- **Multi-Work Customer Profiles**: Manage multiple projects/works per customer, track Quotations vs. Invoices, log multiple advances/installments, and print Customer Statement PDFs.
- **Purchase & Supplier Ledger**: Record material invoices/quotations (UPVC profiles, toughened glass, hardware), track payments, and clear supplier balances.
- **Staff, Overtime (OT) & Salary Tracker**: Log technician OT hours at custom hourly rates, record salary payouts, and view pending balances.
- **Daily Operational Expenses**: Categorized tracking for Staff Food, Petrol, Travelling, Transport, Grocery, and Site Misc.

## How to Deploy on GitHub Pages
1. Extract this ZIP archive.
2. Upload `index.html` and `README.md` to the root of your GitHub repository.
3. Go to **Settings → Pages**, select the `main` branch (`/(root)`), and click **Save**.
